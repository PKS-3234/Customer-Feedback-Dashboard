# Customer Feedback Intelligence Platform - Backend (Spring Boot)

Spring Boot 3.3+ enterprise backend service built on Java 21 and Maven.

## Tech Stack
- Java 21
- Spring Boot 3.3.5
- Spring Data JPA
- PostgreSQL & PGVector
- Flyway Database Migrations
- Spring Boot Actuator

## Setup & Running

```bash
mvn clean spring-boot:run
```

## Running Tests

```bash
mvn test
```
