# Customer Feedback Intelligence Platform - Frontend (Angular 21)

Angular 21 SPA utilizing Standalone Components, Angular Router, and Angular HttpClient.

## Tech Stack
- Angular 21
- Standalone Components
- TypeScript 5.9+
- SCSS
- Vitest

## Setup & Running

```bash
npm install
npm start
```

## Running Tests

```bash
npm test
```

## Production Build

```bash
npm run build
```
